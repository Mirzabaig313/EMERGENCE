# EMERGENCE Examples

This directory contains example scripts demonstrating various features of the EMERGENCE simulator.

## Available Examples

### dashboard_demo.py
Comprehensive demonstration of the statistics and visualization system. Shows:
- Main statistics dashboard
- Population and fitness graphs
- Age and energy distributions
- Heatmaps for births, deaths, and food consumption
- Top performers leaderboard
- Learning curves for individual creatures
- Family tree visualizations
- Data export to JSON/CSV

Run it with:
```bash
python examples/dashboard_demo.py
```
